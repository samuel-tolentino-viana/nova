# 🛍️ NOVA

Site fictício de uma loja virtual desenvolvido para praticar
HTML5, CSS3 e JavaScript.

O projeto apresenta uma coleção de produtos e permite explorar os
itens através de filtros por categoria.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Exibição de produtos
- Organização por categorias
- Filtro de produtos
- Interface responsiva
- Interações com JavaScript

## Categorias

- Roupas
- Calçados
- Acessórios

Praticar a construção de interfaces de lojas virtuais e desenvolver
experiência com manipulação de elementos e interações utilizando
JavaScript.
